# Repository Boundary Proof

## J Merrill One

J Merrill One is the enterprise/business authority and brand umbrella. That business role does not make this application repository the owner of every enterprise platform.

## jmerrillorg/jmerrill-one

This repository owns:

- the `jmerrill.one` public application;
- its App Service deployment workflow and release marker;
- public contact/intake and division navigation;
- the authenticated marketing command-center application surface;
- application code needed to validate governed marketing integrations.

## jmerrillorg/jm1-ops

The enterprise control plane owns:

- Enterprise Financial Core;
- enterprise Purview and retention governance;
- enterprise Power Platform DLP;
- credential-lifecycle governance, including `JM1-MPI-002`;
- cross-repository policy placement and enterprise estate governance.

PR #19 contains unique enterprise governance source but does not transfer that authority into this application repository. PR #6 is enterprise estate evidence, and PR #7 is cross-brand social-recovery evidence. Neither should be merged into application main merely to preserve history.

Cross-repository dependencies do not transfer ownership. No Financial Core, Purview, DLP, or other control-plane implementation is authorized here.
