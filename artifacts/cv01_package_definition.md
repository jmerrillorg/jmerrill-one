# CV-01 - Enterprise Customer Feedback Activation

Status: activation package with human-admin gate.

Customer Voice is JM1's default Microsoft-native feedback platform where survey/feedback semantics fit.

CV-01 is activation, not survey-platform design. J Merrill One owns the shared Customer Voice capability, governance, privacy/security boundaries, reusable standards, Dataverse integration pattern, and cross-division handoff contracts. Division repositories own division survey content, branding, website implementation, and consequential follow-up.

Preferred proof target is JM1-Enterprise-Dev. Customer Voice must be provisioned there and users must have the required Customer Voice roles before a project, survey, and controlled response proof can be completed.
