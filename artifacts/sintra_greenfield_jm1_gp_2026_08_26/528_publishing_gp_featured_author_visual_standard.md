# Publishing Monthly Featured Author Visual Standard

Use the Publishing palette: primary #1E90FF, secondary #6A5ACD, accent #A3C4DC, background #FFFFFF, text #111111.

Every new image must include the approved shared J Merrill logo.

For September 2026, visible treatment should include SEPTEMBER FEATURED AUTHOR and Sean A Crowley I where visually appropriate.

Avoid one rigid template. Rotate between author/title card, reader-discovery card, quote-free theme card, month-launch card, and month-recap card while preserving logo, palette, source accuracy, and rights safety.
