# Sintra Rehome Pattern

Preferred priority:

Authoritative system remains authoritative

Sintra receives only needed projection/reference

Brand-specific scope maintained

One Brain does not become operating authority for every brand

## Application

Rehome does not mean Sintra becomes the new system of record. For Publishing, Financial, Foundation, Productions, and enterprise One records, the authoritative source remains the governed repo, Dataverse, SharePoint, M365, brand workspace, or approved public web canon.

If Sintra supports safe workspace separation, the better pattern is usually a curated projection or reference copy with explicit source provenance. Physical movement is appropriate only when it is reversible, source-backed, and separately approved.
