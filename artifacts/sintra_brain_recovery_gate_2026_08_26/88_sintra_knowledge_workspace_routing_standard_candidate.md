# Sintra Knowledge Workspace Routing Standard Candidate

Status: STANDARD-CANDIDATE

For each knowledge item, ask:

1. What is the authoritative source?
2. Which brand owns the operational subject?
3. Does J Merrill One need this for enterprise understanding?
4. Is a high-level reference enough?
5. Does a branch Sintra workspace exist?
6. Would duplication create drift?
7. Can the branch workspace reference authoritative material instead?

## Preferred Routing

Authoritative source remains canonical. Branch-specific Sintra workspaces consume governed projections or references when useful. J Merrill One receives only high-level enterprise reference where needed.

## Non-Promotion

This is not canon yet. It is a candidate routing standard for Founder review and should not be used to execute record movement, quarantine, deletion, or cross-workspace Brain mutation without separate approval.
