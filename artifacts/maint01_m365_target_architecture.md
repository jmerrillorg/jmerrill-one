# MAINT-01 M365 Target Architecture

HUMANS -> licensed user accounts.
ORGANIZATIONAL COMMUNICATION -> shared mailboxes.
COLLABORATION -> Teams only where people actually collaborate.
AUTHORIZATION -> security groups / Dataverse teams.
WORKLOADS -> managed identity / service principal / app user.
DOCUMENTS -> SharePoint.
DATA -> Dataverse.
CODE -> GitHub.

Not every division/function needs every object type.
