# HFWEB-01 Technical Language Audit

Date: 2026-08-12

## Search Terms

`system`, `systems`, `architecture`, `orchestration`, `operating model`, `infrastructure`, `data layer`, `governance model`, `intelligence system`, `AI orchestration`, `cross-division execution`, `execution layer`, `enterprise system`, `platform`, `control layer`, `governed infrastructure`, `unified data`, `runtime`, `automation architecture`, `agent governance`, `Dataverse`, `Dynamics`, `Power Platform`, `Azure`, `Copilot Studio`.

## Result

Primary public journey root-language was rewritten as human benefit language:

| Original Pattern | Classification | Disposition |
| --- | --- | --- |
| `system`, `outputs of the system`, `system intelligence` | INTERNAL / ROOT LANGUAGE | Rewritten to continuity, care, shared commitment, and next steps |
| `architecture`, `infrastructure`, `one data layer`, `one governance model`, `one intelligence system` | INTERNAL / ROOT LANGUAGE | Removed from homepage and Why page |
| `AI orchestration`, `cross-division execution`, `Power Platform ecosystem` | INTERNAL / ROOT LANGUAGE | Removed from primary proof and division pages |
| `/api/intake`, `Dataverse`, `Dynamics`, `Azure Static Web Apps` | PARTNER / PROCUREMENT LANGUAGE | Preserved only in backend code or secondary partner page; not used as primary marketing value |
| `platform` in productions/media context | PUBLICLY USEFUL when referring to audience channels | Rewritten where it sounded like enterprise infrastructure |
| `Operating Model` | PARTNER / PROCUREMENT LANGUAGE | Removed from primary nav; retained as secondary `How We Work` page |
| `Ecosystem` | REWRITE AS HUMAN BENEFIT | Page retained as `How Our Companies Connect` |

## Remaining Intentional Occurrences

Remaining technical product names appear on `/operating-model` only, where the page is positioned as a secondary enterprise/partner reference. CSS/font-family matches and route/component names are implementation text, not visible public copy.

Default public rule applied: describe the benefit produced by the roots, not the roots themselves.
