# JM1_SERVICE_LIFECYCLE_POLICY_v1.0

Status: CANON-CANDIDATE

Every enterprise service must have owner, purpose, repo/admin surface, current runtime/service version, support status, end date, target state, migration status, monitoring owner, and credential state.

Allowed statuses: CURRENT, SUPPORTED_BUT_LEGACY, DEPRECATED, RETIREMENT_ANNOUNCED, UNSUPPORTED, UNKNOWN. UNKNOWN is a temporary evidence state, not an acceptable operating state.
